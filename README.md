# Khel Bharat

Toys and games from India's civilisation, history and culture, built for Smart India Hackathon 2026,
Problem Statement 26208 (Student Innovation, Toys & Games, AICTE).

Five playable games in five languages (English, Hindi, Tamil, Bengali, Telugu). Open `index.html` in any browser. There is no build step and no backend.

| Game | Roots |
|------|-------|
| Moksha Patam | The original snakes and ladders. Ladders are virtues, snakes are vices. Play against the computer. |
| Smriti | Memory match on 8 Indian monuments. |
| Patang | 30-second kite-cutting arcade game for Makar Sankranti, with combos and golden kites. |
| Pallanguzhi | South Indian seed-sowing game (7 pits a side) against a computer opponent. |
| Itihaas Quiz | Six questions on games, history and culture. |

Heritage points and best scores are saved in the browser's localStorage. The language choice is remembered too.

## Publish it

Settings > Pages > deploy from the `main` branch, root folder.
